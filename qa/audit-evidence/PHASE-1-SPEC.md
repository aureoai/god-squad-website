PROJECT:

TARGET:
Production-ready Shopify Online Store 2.0 theme

PHASE:
1 — WEBSITE AUDIT

============================================================
PRIMARY OBJECTIVE
============================================================

Perform a complete professional audit of the existing God Squad website.

The purpose of this phase is to understand exactly what currently exists before implementation begins.

Do not modify the website during this phase.
Do not redesign anything.
Do not convert anything to Shopify yet.
Do not delete anything.
Do not rename production files.
Do not replace images.
Do not install dependencies.
Do not install Shopify apps.
Do not fabricate missing business information.

The output of this phase is an AUDIT REPORT and IMPLEMENTATION BLUEPRINT.

============================================================
1. INSPECT THE ENTIRE PROJECT
============================================================

Start by recursively inspecting the entire project.

Inspect: HTML, JavaScript, CSS, images, uploaded assets, logos, icons, sprites, mockups, duplicate files, external dependencies, embedded scripts, custom runtime code, hardcoded content, responsive CSS, navigation, interactive elements.

Record: filename, location, file type, file size, dimensions where applicable, purpose, whether actively used, whether duplicated, whether production-ready, whether it should eventually be migrated to Shopify.

Do not assume that a file is unused merely because its filename looks unrelated. Verify usage from the source code.

============================================================
2. CURRENT PROJECT ARCHITECTURE AUDIT
============================================================

Determine exactly how the current website works.

Document: entry HTML file, JavaScript runtime, rendering system, custom elements, data system, product data, values data, CSS architecture, inline styles, external fonts, image loading, interaction handling, responsive handling.

Identify custom runtime dependencies.

Specifically inspect the relationship between: God Squad Website.dc.html, support.js, x-dc, DCLogic, sc-for, sc-if, data-dc-script.

Determine whether these are suitable for a production Shopify theme. Document the result clearly.

============================================================
3. HTML / MARKUP AUDIT
============================================================

Inspect the HTML structure.

Check for: semantic HTML, heading hierarchy, section structure, navigation structure, buttons, links, images, forms, duplicate attributes, invalid attributes, placeholder links, empty links, unnecessary wrappers, accessibility issues, maintainability issues.

Identify CRITICAL / HIGH / MEDIUM / LOW severity issues. Do not fix them yet.

============================================================
4. CSS AUDIT
============================================================

Analyze the CSS architecture.

Identify: inline CSS, embedded CSS, duplicated declarations, media queries, hardcoded colors, hardcoded spacing, hardcoded typography, inconsistent breakpoints, repeated styles, !important usage, nonstandard attributes used for styling, hover behavior, responsive behavior, maintainability problems.

Determine whether the current CSS can reasonably be migrated to a Shopify theme. Recommend the future CSS architecture. Do not rewrite CSS yet.

============================================================
5. BRAND & DESIGN AUDIT
============================================================

Evaluate the existing visual system.

Review: COLOR, TYPOGRAPHY, SPACING, GRID, IMAGERY, BUTTONS, NAVIGATION, ICONS, PRODUCT CARDS, EDITORIAL SECTIONS, FOOTER, VISUAL HIERARCHY.

Current brand direction: GOD SQUAD — FAITH-DRIVEN PREMIUM STREETWEAR

Primary palette: #0D0C0A, #F3EFE6, #D8C08A
Typography: Playfair Display, Jost, Kaushan Script

Determine: what should remain unchanged, what should be refined, what is inconsistent, what needs standardization. Do not change the visual identity.

============================================================
6. HOMEPAGE UX AUDIT
============================================================

Audit the entire homepage.

Current intended flow:
1. Announcement Bar
2. Header
3. Hero
4. New Drop
5. Best Sellers / Product Discovery
6. Our Story
7. Brand Values
8. Verse / Faith
9. Social / Community
10. Footer

For every section document: PURPOSE, CURRENT IMPLEMENTATION, UX QUALITY, PROBLEMS, OPPORTUNITIES, SHOPIFY IMPLEMENTATION, PRIORITY.

Determine whether the section should be: KEEP, IMPROVE, REBUILD, REPLACE, ADD LATER.

============================================================
7. HEADER & NAVIGATION AUDIT
============================================================

Audit: desktop navigation, mobile navigation, logo, search, account, cart, menu, announcement bar, active state, hover state, navigation URLs.

Identify every placeholder or nonfunctional interaction. Check links using href="#" and other placeholder destinations. Determine what each navigation item should eventually connect to.

Expected future architecture: HOME, SHOP, COLLECTIONS, OUR STORY, VERSE. Utility: SEARCH, ACCOUNT, CART. Do not implement them yet.

============================================================
8. HERO AUDIT
============================================================

Audit: WALK BY FAITH. / 2 CORINTHIANS 5:7 / STREETWEAR WITH A PURPOSE / DIFFERENT PEOPLE. SAME PURPOSE / MORE THAN CLOTHING. / A HIGHER PURPOSE.

Evaluate: visual hierarchy, readability, image composition, contrast, typography, CTA strategy, desktop layout, tablet layout, mobile layout, LCP implications, image quality, accessibility.

Determine whether the hero should: KEEP, POLISH, REBUILD. Provide exact recommendations.

============================================================
9. PRODUCT / COLLECTION UX AUDIT
============================================================

Current product concepts include: Signature Oversized Tee, Heavyweight Hoodie, Utility Cap.

Audit: product cards, product image quality, product names, pricing, swatches, product hierarchy, hover behavior, quick add, product links, collection links, mobile behavior.

Identify which information is currently hardcoded. Explain how it should eventually become Shopify dynamic data.

Future Shopify objects may include: product, collection, product.title, product.price, product.featured_image, product.images, product.variants, product.available, product.url. Do not implement this yet.

============================================================
10. SHOPPING UX GAP ANALYSIS
============================================================

Determine what is currently missing for a real ecommerce experience.

Audit: product page, collection page, search, cart, cart drawer, add to cart, quantity controls, variants, availability, checkout pathway, customer account, wishlist, filters, sorting, product recommendations, related products.

For every feature classify: CURRENT, MISSING, REQUIRED, OPTIONAL, BUSINESS DECISION REQUIRED. Do not invent functionality.

============================================================
11. OUR STORY AUDIT
============================================================

Current brand story: God Squad is a Philippine streetwear brand built on faith, creativity, and community.

Evaluate: storytelling, readability, image composition, CTA, mobile experience, emotional hierarchy, authenticity, Shopify editability. Determine what should eventually become editable in the Theme Editor.

12. BRAND VALUES AUDIT
============================================================

13. FOOTER AUDIT

============================================================
14. RESPONSIVE / MOBILE AUDIT
============================================================

Analyze the actual responsive CSS. Inspect @media(max-width:900px) and @media(max-width:520px).

Evaluate: 375px, 390px, 430px, 768px, 900px, 1024px, 1280px, 1440px+.

Check: navigation, hero, product grid, story, values, footer, typography, spacing, image cropping, touch targets, horizontal overflow, readability, CTA accessibility.

Identify desktop-first problems. Do not fix them yet.

============================================================
15. ACCESSIBILITY AUDIT
============================================================

Check: semantic HTML, heading hierarchy, alt text, decorative images, interactive icons, buttons, keyboard navigation, focus states, contrast, touch target sizes, mobile navigation, screen reader labeling, reduced motion, links.

Identify every major issue. Categorize: CRITICAL, HIGH, MEDIUM, LOW. Do not fix yet.

============================================================
16. SEO AUDIT
============================================================

Inspect: <title>, meta description, canonical, Open Graph, social metadata, favicon, robots, structured data, semantic headings, image alt text, URLs, content hierarchy.

Determine what exists and what is missing. The final Shopify theme should have a proper SEO foundation. Do not implement SEO yet.

============================================================
17. PERFORMANCE AUDIT
============================================================

Inspect: image file sizes, image dimensions, image formats, duplicate assets, sprites, JavaScript size, CSS size, font loading, external resources, render blocking resources, lazy loading, hero image loading, DOM complexity.

Pay particular attention to: hero-group.png, icons-sprite.png, social-sprite.png. Identify large assets and unnecessary duplicates. Do not optimize files yet.

============================================================
18. ASSET AUDIT
============================================================

Create an asset inventory. Classify every asset: KEEP, OPTIMIZE, REPLACE, ARCHIVE, REMOVE, UNKNOWN.

Identify exact duplicate files using file hashes where possible. Do not delete duplicates during Phase 1. Document them.

Also identify: master assets, web assets, mockup assets, reference screenshots, temporary/generated assets.

21. JAVASCRIPT AUDIT
============================================================

Audit support.js. Determine: purpose, dependency, runtime architecture, bundle size, unnecessary functionality, Shopify compatibility, maintainability, security concerns, future replacement strategy.

Specifically identify: DCLogic, React runtime assumptions, custom parser, custom renderer, custom elements, custom interpolation, event handling.

Determine whether this should be: KEEP, REPLACE, REMOVE DURING SHOPIFY CONVERSION. Do not modify support.js.

============================================================
22. DATA ARCHITECTURE AUDIT
============================================================

Identify all hardcoded content. Especially: products, prices, swatches, values, navigation, URLs, currency, text, images.

Document what should eventually become: Shopify product data, Shopify collection data, Theme settings, Section settings, Block settings, Navigation menus, Metafields, Shopify settings, Business configuration.

============================================================
23. SHOPIFY COMPATIBILITY AUDIT
============================================================

Evaluate the current website against Shopify Online Store 2.0.

Check: theme structure, Liquid compatibility, JSON templates, sections, blocks, snippets, assets, configuration, locales, product data, collections, cart, search, customer accounts, Theme Editor.

The final theme should use Shopify-native architecture. Recommended target: layout/, sections/, snippets/, templates/, assets/, config/, locales/.

Use JSON templates where section customization is appropriate. Use section groups for areas such as header and footer where appropriate. Shopify's current documentation states that JSON templates allow sections to be added, removed and reordered through the Theme Editor, while section groups provide the same flexibility for layout-controlled areas such as headers and footers.

============================================================
24. FUTURE SHOPIFY ARCHITECTURE RECOMMENDATION
============================================================

Based on the audit, recommend a target architecture such as: god-squad-theme/ with assets/, config/, layout/, locales/, sections/, snippets/, templates/.

Potential sections: announcement-bar.liquid, header.liquid, hero.liquid, featured-collection.liquid, best-sellers.liquid, our-story.liquid, brand-values.liquid, verse.liquid, social-gallery.liquid, footer.liquid.

Potential snippets: product-card.liquid, icon-search.liquid, icon-account.liquid, icon-cart.liquid, icon-menu.liquid, icon-close.liquid, icon-arrow.liquid.

Potential templates: index.json, product.json, collection.json, cart.json, search.json, page.json, 404.json.

This is a recommendation only. Do not create the Shopify theme during Phase 1.
